# 基于视觉 Token 撤出的多模态大模型快速推理 · 交互式教程（v7.3 长滚动版）

论文：*Boosting Multimodal Large Language Models with Visual Tokens Withdrawal for Rapid Inference*（AAAI 2025，Vol. 39 No. 5，pp. 5334–5342；Zhihang Lin, Mingbao Lin, Luxi Lin, Rongrong Ji）。

## 本地运行

```bash
npm install
npm run dev       # 开发预览
npm run build     # 产出 dist/
```

调试参数：`?motion=reduce`（与系统“减少动态效果”同一条路径：时间轴停在终态、不自动播放，CSS 过渡也关闭）、`?all=1`（一次展开全部章节）、`?tl=0.5`（1.1 / 4.1 / 5.1 的时间轴从该进度开始、不自动播放，用于检查各阶段画面）、`#chap-N` / `#closing` / `#glossary` / `#sources` / `#videos`（打开时直接定位）。

## 版式

参照 PaperSkill 仓库中的长滚动成品 DivPrune v9（`html_output/divprune_…/yuhaoyang1026/`）：

- 左侧固定章节栏 288px；窗口不足 1280px 时收为抽屉（顶栏“章节”按钮打开，点遮罩或 Esc 关闭）。
- 主区一列白色卡片（章卡最宽 1064px），正文 15–17px、章标题 26px、模块标题 17px，背景为浅色光晕。
- 封面：英文标题渐变字、中文标题与作者、摘要、关键词、原模型 / VTW 两侧同时钟对比动画（进入视口播放一次，可重播）、四个关键数字、三条阅读路线、读前须知、“开始学习 §1”。
- 章节逐章展开：每章末尾“继续 §N+1”，侧栏或章内进度条可直接跳到任一章（会展开到该章为止）。
- 每章自上而下：本节问题（与导语合并为一段）→ 类比（只在第 4、6 章，含类比边界）→ 交互模块（每个模块一张卡片：怎么操作、看什么变化 + 交互 + 折叠的“出处与口径”）→ 洞察 → 公式（符号可悬停 / 聚焦 / 点按）→ 符号与推导 → 核对 → 关键数字 → 要点 → 常见误区 → 深入阅读（折叠）。v7.1 起，每章只显示有独立信息的栏目，由 `chapters.ts` 的 `show` 指定。
- 收束：结论分级（逐条分级的交互 + 三栏完整分级 + 复述五问）、术语表（22 条）、来源与证据边界。
- 末尾 B 站视频推荐：三段与 VTW 对应的模型背景、注意力汇现象、FastV 方法对照，卡片样式沿用 DivPrune。均为外链，不内嵌播放器；标题、UP 主、时长已核对，封面引用 B 站原图床。

交互模块有两类：

- **容器适配**（v7.2 起：1.1、4.1、5.1、6.1）：画布按卡片实际宽度绘制（HiDPI），字号、线宽与控件用网页真实尺寸，不经整体缩放；卡片内容宽度不足 700px 时画布在上、控件在下（容器查询），手机上不再横向滚动。代码在 `src/live/`。
- **整体缩放**（其余 14 个）：沿用 v6 的页面组件（按 1472 × 622 设计单位绘制），由 `ZoomBox` 按卡片宽度缩放：取 min(0.62, 卡片宽 / 1472)，不低于 0.5；再窄时在卡片内横向滚动。

## v7.2 体验回迁（2026-11-01）

依据 Codex 的《VTW v5.1 与 v7.1：体验对比及改进建议》，保留 v7.1 的白色长网页、侧栏与去重成果，回迁 v5.1 的过程动画与控件行为。

明确问题的修复：

- **首次章节定位偏移**：从封面直接点侧栏第 10 章时，新展开的模块会在首帧后校准尺寸，旧代码按校准前的位置滚动（报告复现为标题在视口上方约 827px）。现在展开后先对齐一次，主区尺寸仍在变化时跟着重新对齐（连续 300ms 不变或满 3 秒即停止），读者滚动、按键或点击时立即停止；对齐用 `behavior: 'instant'`，不受 CSS 平滑滚动影响。
- **封面茶包提起被终态覆盖**：`TeaCup` 以前看到 `bag = 'up'` 就把位置设为最高点，忽略传入的连续 `lift`。现在 `bag` 只表示语义状态，绘制位置读 `lift`；不传 `lift` 时仍按 `bag` 画终态。
- **分段控件**：恢复方向键 / Home / End 切换与 roving tabindex（Tab 只停在当前项）；选中指示器在选项之间平移（0.34 s），文字颜色同步过渡（0.24 s）；按钮统一加按压与焦点反馈，反馈文字换内容时轻微淡入。

核心过程回迁（沿用当前核对过的 K 口径、数据与计算规则）：

- **5.1 撤出过程**：token 通道逐层上升 → 到撤出边界时视觉通道停下、散开撤走 → 文字通道继续上升；原模型与 VTW 的累计计算量随同一进度分开增长，算账时给出总比例。可播放、暂停、重播、拖动进度、点四个阶段按钮；K 与两种层号口径（代码 / Eq. (5)）仍可切换，原来的“观察层 ℓ”即时间轴进度（读数“算到第 ℓ 层”）。
- **4.1 信息迁移**：计算逐层推进，信息只沿因果允许的方向（视觉 → 后面的问题 token）流动，问题 token 的茶色逐层上涨；越过第 K 层后视觉 token 撤走，已吸收的信息保留。系统 token 始终读不到；“让视觉 token 读问题？”显示因果掩码的阻断。茶杯保留并与画布同一进度驱动（茶色 = 已吸收的信息，越过 K 后茶包连续提起）。吸收比例仍是教学设定（每层 42%），画面不标数。
- **1.1 图像到 token**：一张示意图被切成 24×24（NeXT 示意为 45×44）块 → 飞进输入序列 → 在 32 层里逐层付费；原来的序列占比与 Eq. (1)、Eq. (2) 核对放在同一侧栏，读数随同一状态更新。示意图改为白天湖景，配合浅色主题。

更新策略与性能：

- `useTween`：离散切换约 0.4 s 过渡；连续拖动（两次变化间隔 < 140 ms）直接到位，不在图形后面拖尾；新目标从当前显示值转向，不排队回放；标签页隐藏时直接到终值，rAF 被节流时到点也落到终值。
- 6.1 改为容器适配的画布：柱子与读数同时到位（读数不再单独缓动 360 ms）；一次跳过多层时撤出线与柱子一起短暂过渡。
- `useReducedMotion` 整页共用一个 MediaQueryList（`useSyncExternalStore`），不再每次渲染重建监听；`?motion=reduce` 现在真正生效（此前文档写了但代码未读取）。
- 环境时钟（水汽）与画布舞台离屏或标签页隐藏时停止调度帧，回来再恢复。
