# DivPrune v9：修改说明（改回长滚动版式）

基于 v8 全片（`divprune-tutorial-v8-ppt-full.zip`，未改动）。按反馈“内容太大、太满”，参照 PaperSkill 长滚动模板的页面
（`reducttech.github.io/PaperSkill/papers/black_box_adaptive_…/zhangdemin0903/`）调整页面大小与总体布局，并在最后加入 B 站推荐视频。

## 一、版式：从 PPT 播放器改回长滚动

| 项目 | v8（PPT 播放器） | v9（参照页） |
|---|---|---|
| 外壳 | 1600×900 固定画布一页一屏，整体缩放 | 左侧固定章节栏 288px + 主区一列卡片（章卡最宽 1064px，内边距 32px） |
| 推进方式 | 翻页 | 封面“开始学习 §1”，每章末尾“继续 §N+1”逐章展开；侧栏或章内进度条可直接跳到任一章 |
| 正文字号 | 28 / 34 / 44px（缩放后约 18–29px） | 正文 15–17px，章标题 26px，模块标题 17px，与参照页一致 |
| 交互模块 | 每页塞满 1472×622 | 每个模块一张卡片（头部 + 一句说明 + 交互 + 折叠的“出处与口径”），高度随内容 |
| 各章开场 | 左情节 + 右三层阅读（标签切换） | 不再用标签：本节问题、测绘队情节、洞察、公式、核对、关键数字、要点与误区依次排在章内；原版“深入阅读”折叠在章末 |
| 收束 | 3 页 | 一章三张卡片（结论分级、术语表、来源与证据边界） |
| 视频 | 无 | 末尾“延伸学习 · B 站讲解视频”（与模板 BiliVideos 同一套卡片结构） |

实现方式：交互模块的计算与绘制代码不变，仍按设计单位书写，外层用 CSS `zoom: 0.62` 整体缩到参照页的字号（28px × 0.62 ≈ 17px）；
PPT 版里绝对定位的“上控制条 + 左画布 + 右面板”改为自然排版（右面板高度随内容，不再把反馈推到底部）。
测绘队情节缩到 0.56、封面对比动画缩到 0.7。6.1 的条目列表恢复正常行距（PPT 版为塞进一屏压得很紧）。

## 四、检查情况

- `npx tsc --noEmit` 无错误；`npm run build` 通过。
- 1440×900、`?motion=reduce&all=1` 下，对封面、10 个情节卡片和 20 个模块卡片（共 31 张）逐个做了 335 次状态检查：每个分段选项、开关、下拉选项、列表 / 芯片按钮、
  “下一步 / 落下一针 / 找一个反例 / 换一组”、每个滑块的最小 / 中间 / 最大值，以及展开“出处与口径”。每次检查：卡片内没有元素越出卡片、没有被裁切的元素、
  画布内没有越界的文字、页面无运行时错误。结果全部为空。
- 阅读流程：初始只显示封面；“开始学习”展开 §1 并定位；“继续”逐章展开；侧栏跳到 §7 时展开到 §7；章内进度条跳转；侧栏最后一项展开收束与视频。
- 375px 宽：页面无横向滚动；章节栏收为抽屉（“章节”按钮打开，点遮罩关闭）；交互模块在卡片内横向滚动。
