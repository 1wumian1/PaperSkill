# DivPrune v9.3：中间窗口宽度（961–1279px）的共用布局

基于 v9.2。配色、渐变、卡片质感、教学内容与交互都不变；保留 v9.1 的性能优化（屏外暂停、有限时长重绘、封面播完停止、速度选择）、
v9.2 的 4.1 向量边界与第 6 章筛选联动，以及第 9 章实测 / 示意的区分。字号不变，没有缩小整页、隐藏数据、裁切或整页横向滚动。

## 一、原因

**1. 侧栏断点与模块最小宽度不匹配。** 侧栏 288px 只在 960px 以下收起。961px 时侧栏重新出现，
模块正文区从 877px 骤降到 534px（侧栏 288 + 主区内边距 + 章卡内边距 + 模块内边距共占约 427px）。
交互模块按设计单位书写、整体按 0.62 缩放，要放下“左画布 + 右面板”大约需要正文区 850px（设计宽约 1370）。
所以 961–1279px 这一段里，正文区一直不够：961 宽 534px、1024 宽 597px、1100 宽 673px、1200 宽 773px，到 1280 才达到 853px。

**2. 模块内部有固定列宽或不换行的行。** 正文区一窄，这些地方就越出卡片或互相压住：
- 7.1：表格固定 900 设计单位，右侧统计卡被挤出卡片（1100 宽越界 107px，1200 宽仍越界 7px）。
- 9.1：左侧参数区固定 600，右侧数据集列表的名称列固定 176 且不换行，名称压到百分比上，数值被截。
- 10.1 / 10.2：左侧固定 920；10.2 每根柱宽固定 48，柱下标签互相重叠。
- 收束页：结论分级 780、术语表 920、来源 860 固定列。
- 分段按钮（1.1 / 1.2 / 6.1 等）和 5.1 顶部工具条不换行。
- B 站卡片标题限两行截断。

## 二、修复（`src/styles/v9.css`，另有 `App.tsx` 与 `dp-m4-cosine.tsx` 各一处小改动）

**侧栏提前收起。** 新增 `@media (max-width: 1279px)`：显示顶栏“章节”按钮，侧栏改为抽屉（点按钮打开，点遮罩、按 Esc、点章节或把窗口拉宽到 1280 以上都会收起），
主区去掉 288px 左边距，主区 / 章卡内边距略收。正文区变为“视口 − 约 107px”：961 宽 854px、1024 宽 917px、1100 宽 993px，1152 以上封顶在章卡最大宽度（1012px）。
1280px 起和原来一样常驻侧栏。960px 以下的手机布局没动。

**模块内部改为可换行的弹性行。** 空间不足时左右布局变上下布局，字号不变：
- 7.1：表格（基准 860）与统计卡（基准 360）放进可换行的弹性行，放不下时统计卡移到表格下方。
- 9.1：参数区与结果区可换行；读数卡最小 300 设计单位，自动排成 1–3 列，“0.512 / 3.228”不再断行；
  数据集列表名称列改为可伸缩区间（150–210）并允许换行，数值列按内容宽度，名称与百分比各占一列。
- 10.1 / 10.2：左右两栏可换行；10.2 的柱宽改为均分。
- 收束页三处固定列改为可伸缩比例列；术语按钮允许换行。
- 分段按钮和 5.1 / 7.1 顶部工具条允许换行。
- 三项读数（5.2 等）最小列宽从 170 调到 210，“100.0%”不再被截。
- 4.1：读数标题里的公式（“1 − cos θ”“‖γ − ω‖”）保持在同一行，换行只发生在公式之前。
- B 站卡片标题完整显示，卡片列数随宽度变化。

## 三、验证

### 检查方式

- **浏览器视口模拟**（本轮全部检查都属于这一类）：Claude 桌面应用内置浏览器窗格。宽度检查页 `tools/measure/widths.html` 把教程放进同源 iframe，
  逐个设置 iframe 宽度，记录的是**教程页面自身的 `window.innerWidth`**（不是窗格外框）。高度：1024 及以下 768，其余 900。
  `layout.js` 对每张卡片（32 张）检查三类问题：元素越出卡片、元素内部被裁切（scrollWidth / scrollHeight 大于可见尺寸）、文字与文字重叠（逐个文本节点的行矩形）。
  带状态扫描时还会切换每个分段、开关、列表按钮、滑块最小 / 最大值、展开“出处与口径”，每个宽度 213 个状态。
- **前台可见窗口检查**：未做。本轮浏览器窗格一直处于后台（隐藏），截图在后台渲染。
- **真实设备检查**：未做，没有使用实体 1366×768 显示器。
