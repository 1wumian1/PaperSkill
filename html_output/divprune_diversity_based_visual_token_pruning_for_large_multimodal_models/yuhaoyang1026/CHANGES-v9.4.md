# DivPrune v9.4：手机竖屏下 4.1 / 5.1 / 8.1 与 6.1 的排列

基于 v9.3。桌面布局、内容、视觉风格不变；没有再减小缩放比例（手机上仍是 0.5），也没有隐藏内容。

## 原因

- 960px 以下原本有一条“左画布 + 右面板改为单列”的规则，但它写在文件前面；v9.2 为窄桌面加的双列规则
  （`minmax(420px, 760px) minmax(520px, 1fr)`）选择器相同、写在后面，于是在手机上也生效。
  390 宽时模块正文区只有约 614 设计单位，两列至少要 968，右侧面板被推到卡片外，只能在模块里横向拖动才看得到。
  原来那条单列规则本身也是固定 760 设计单位宽，同样放不下。
- 6.1 的条目列表固定 400 设计单位宽，手机上右侧所选内容只剩一窄条，逐字竖排。

## 修复（`src/styles/v9.css`）

- 删掉 960 断点里固定 760 宽的单列规则（它一直被覆盖，没有起作用）。
- 在文件**末尾**新增 `@media (max-width: 720px)`，保证排在双列规则之后：
  - 4.1、5.1、8.1（以及其他同样是“画布 + 面板”的模块，如 2.1、3.1、4.2、5.2、6.2）改为单列：图在上，控制与反馈在下。
  - 6.1 改为单列：条目列表在上（取消 400 宽的固定左列，条目文字可换行），所选内容在下；较长的代码路径允许在路径中换行。
- 720px 以上不受影响。

## 验证（浏览器视口模拟，后台窗格）

- 宽度检查（`tools/measure/widths.html` + `layout.js`，记录页面自身 innerWidth）：
  360、390、430 宽下，4.1 / 5.1 / 6.1 / 8.1 在默认状态和全部状态（分段、开关、列表按钮、滑块最小 / 最大、展开出处）下都没有越界、裁切或文字重叠。
  修改前 390 宽时这四张卡片都有越界（右侧面板越出约 198px），6.1 还有裁切。
- 4.1 九组角度 × 长度、6.1 十三步联动（`recheck.js`）在 390×844 下全部通过，页面无横向滚动。
- 720、721、960、961、1100、1280、1440 宽默认状态复查：0 个问题，侧栏状态与正文区宽度和 v9.3 相同。
- 截图：390×844 下修改前 4.1 / 6.1，修改后 4.1 / 5.1 / 6.1（列表、内容）/ 8.1。
