# DivPrune v9.5：手机收尾（结论分级、术语表、宽表提示、方位用词）

基于 v9.4。桌面布局、内容、视觉风格和整体缩放比例都不变（手机上仍是 0.5），只改排列、换行与说明文字。

## 一、收束页「结论分级」

**原因**：列表和详情固定左右两栏（v9.3 改成 `1.3fr / 340` 的比例列），手机上列表只剩约 81px 宽，完整句子被拆成很多短行。

**修复**：在现有手机断点（≤ 720px）改为单列——条目列表在上，所选详情在下；条目文字自然换行完整显示，每条点按高度不小于约 38px。
分类切换、选中状态与详情仍由同一份状态驱动（切换分类时选中第一条）。

## 二、收束页「术语表」

**原因**：词条区固定三列，手机上词条区只有约 81px 宽，按钮被撑出词条区，伸到右侧说明面板下面；说明面板在 DOM 里排在后面，
盖住了这些按钮，点击落在面板上。390 宽时 22 个词条中有 14 个被盖住（包括「视觉 token」），所以点了不切换；1024 宽时两栏够宽，不重叠，所以正常。

**修复**：手机上改为单列——词条按钮区在上，解释在下；按钮区按可用宽度自动排列（360 宽 1 列，390 / 430 宽 2 列），按钮文字可换行，点按高度约 38px。两块上下排列，互不遮挡。

## 三、两项小调整

- **7.1 宽表、10.2 宽图**：改为在表 / 图自己的容器里左右滑动（新增 `XScroll` 组件，`dp-kit.tsx`），容器上方显示「左右滑动查看完整内容 →」。
  提示只在内容确实放不下时出现，放得下时不显示；可滑动时容器可用键盘聚焦（Tab 后用方向键滚动）。10.2 在手机上每组柱子保留可读宽度。
  模块本身和整页都不再横向滚动。
  7.1 表头在手机上保持单行（表格本身可滑动，不必逐字折行）。
- **10.2 第二视图（Fig. 1 的平均方式）**：复查 720 / 721 宽时发现数值标签“3.228 (100.0%)”被截，改为可在括号前换行；排名行的两列固定宽改为可伸缩区间。
- **方位用词**：6.1 说明改为“在条目列表里选一处对照，所选内容给出论文怎么说、代码怎么做……”；
  8.1 说明改为“图示区域是示意图块场景……结果区域是 Table 4 实测分数”；8.1“出处与口径”里的“左侧 / 右侧”同样改为“图示区域 / 结果区域”。

## 四、验证（全部为浏览器视口模拟，后台窗格）

**实际验证过**

- 结论分级、术语表交互（`tools/measure/closingcheck.js`，360×800、390×844、430×932）：
  对每个分类、每个条目、每个词条，先滚到可见处，取按钮中心点上的元素（确认没有被别的元素盖住）并对它点击，再核对选中项与详情。
  - 结论分级：3 个分类 × 各 5 条，三种尺寸下全部可点中、选中项与详情标题一致、分类按钮状态正确；列表在详情上方。
  - 术语表：22 个词条三种尺寸下全部可点中、完整显示、切换后标题一致；「视觉 token」→「视觉 token」；
    抽查头部「大型多模态模型」、中部「VTW」、末尾「CIDEr」均正确。按钮区在解释上方。
  - 同一脚本在修改前（v9.4）390 宽下：22 个词条有 14 个被盖住、点了不切换，其中包括「视觉 token」；结论列表宽约 81px。
- 7.1 / 10.2（360、390、430、720、721、1024、1366）：手机宽度下出现提示、容器可左右滑动、滑到最右时最后一列（7.1 的 Avg、10.2 的 SQA 组）完整可见；
  模块本身不横向滚动；整页无横向滚动。7.1 在 720 及以上放得下、无提示；10.2 在 720 时仍需滑动（有提示），721 及以上放得下、无提示。
- 宽度检查（`widths.html` + `layout.js`，带全部状态扫描）：见下方“扫描结果”。
- 宽度检查对 720 宽 10.2 报的一处“文字重叠”是误报：被报的柱顶数值在滑动区可见范围之外（x = 464 > 可见右边界 447），实际被滑动区裁掉，没有画在右侧说明上。
- 6.1、8.1 新说明文字已进入构建（构建产物中不再有“左边论文 / 左边是示意 / 左侧为教学示意”）。
